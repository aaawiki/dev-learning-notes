# 苍穹外卖项目知识点笔记

## 一、Controller 接收参数的三种形式

| 形式 | 注解 | 示例 | 传参方式 |
|---|---|---|---|
| JSON 请求体 | `@RequestBody` | `login(@RequestBody EmployeeLoginDTO dto)` | POST body：`{"username":"admin"}` |
| Query 参数 | 不加注解 / `@RequestParam` | `page(EmployeePageQueryDTO dto)` | URL：`?page=1&pageSize=10` |
| Path 参数 | `@PathVariable` | `startOrStop(@PathVariable Integer status)` | URL：`/status/1` |

三种可以**混合使用**，互不冲突。

## 二、Query 参数 vs Path 参数

| | Path 参数 | Query 参数 |
|---|---|---|
| 位置 | URL 路径 `{}` 占位 | URL `?` 后面 `key=value` |
| 必须性 | 缺了会 404 | 可省略，取 null |
| 语义 | 标识"操作哪个资源" | 筛选/条件/分页 |
| 注解 | `@PathVariable` | 不加 / `@RequestParam` |

**POST 也能带 query 参数**：请求方法（GET/POST）和 URL 独立，POST 的 body 和 query 互不影响。

## 三、JWT 登录返回 token 流程

```
前端 POST {username, password}
  → @RequestBody EmployeeLoginDTO
  → EmployeeService.login() 校验
  → Controller 生成 JWT
  → 返回 EmployeeLoginVO {id, userName, name, token}
```

**Service 校验三步**：① 用户名存在 ② 密码 MD5 后比对 ③ 账号未禁用

**生成 JWT**：
```java
claims.put("empId", employee.getId());        // 只放员工 id
JwtUtil.createJWT(secretKey, ttl, claims);     // HS256 签名 + 过期时间
```

**核心概念**：
- **claims**：JWT Payload 里的自定义键值对，存业务数据（如 `empId`）
- **secretKey**：签名密钥，防止 token 被伪造（生产环境不能用弱密钥如 `itcast`）
- **ttl**：过期时间，`7200000` 毫秒 = 2 小时

## 四、MyBatis 动态 SQL

### `<set>` 标签
- 自动加 `SET` 前缀，自动删除**末尾**多余逗号
- 等价于 `<trim prefix="SET" suffixOverrides=",">`
- 每个 `<if>` 里留逗号，靠 `<set>` 兜底，任意组合都正确

### `<where>` 标签
- 自动删除**开头**多余的 AND/OR

### 常见坑
1. **XML 属性引号必须闭合**：`<if test="status != null">`（漏引号导致"意外的标记"）
2. **`where` 要放 `</set>` 外面**，不能包在 `<set>` 里
3. **字段名全小写下划线**：`id_number`、`update_time`（不能写 `id_Number`）
4. `<update>` 标签要有 `</update>` 闭合
5. 多参数方法要用 `@Param` 注解

## 五、ThreadLocal 使用链路

```
请求 → 拦截器 preHandle：解析 JWT → BaseContext.setCurrentId(empId)
     → Service：BaseContext.getCurrentId() 取当前用户 id
```

- `BaseContext` 定义 `ThreadLocal<Long>`，提供 set/get/remove
- **隐患**：`removeCurrentId()` 未被调用，需在拦截器 `afterCompletion` 清理，避免线程复用导致数据串扰/内存泄漏

## 六、拦截器 `handler` 参数

```java
if (!(handler instanceof HandlerMethod)) {
    return true;   // 静态资源等非 Controller 方法直接放行
}
```
- `handler` = 当前请求的目标处理器
- `HandlerMethod` = Controller 业务方法；其他 = 静态资源处理器
- 判断目的：只对业务接口做 JWT 校验，静态资源直接放行

## 七、Docket（knife4j 接口文档）

```java
new Docket(DocumentationType.SWAGGER_2)
    .apiInfo(apiInfo)                                     // 文档标题/版本/描述
    .select()
    .apis(RequestHandlerSelectors.basePackage("com.sky.controller")) // 扫描包
    .paths(PathSelectors.any())                           // 所有路径
    .build();
```
- 生成接口文档数据，配合 `addResourceHandlers` 映射 `/doc.html` 页面展示
- 访问 `http://localhost:8080/doc.html`

## 八、静态资源映射

```java
registry.addResourceHandler("/doc.html").addResourceLocations("classpath:/META-INF/resources/");
registry.addResourceHandler("/webjars/**").addResourceLocations("classpath:/META-INF/resources/webjars/");
```
- **关键**：继承 `WebMvcConfigurationSupport` 会导致 Spring Boot 默认静态资源映射失效，必须手动 `addResourceHandlers`

## 九、JacksonObjectMapper 日期序列化

```java
.addDeserializer(LocalDate.class, new LocalDateDeserializer(DateTimeFormatter.ofPattern("yyyy-MM-dd")))
.addSerializer(LocalDate.class, new LocalDateSerializer(...))
```
- **Deserializer**：JSON → Java 对象（反序列化）
- **Serializer**：Java 对象 → JSON（序列化）
- 解决 Java 8 时间类型转换格式问题
- 通过 `extendMessageConverters` 注册到消息转换器生效

## 十、DTO vs Entity

| | DTO | Entity |
|---|---|---|
| 作用 | 接口层数据传输 | 数据库表映射 |
| 字段 | 前端需要传的字段 | 数据库全部字段 |

**为什么用 DTO 接收**：
1. **安全**：防止前端越权传参（如篡改 `status`、`createUser`）
2. **后端字段自己控制**：密码/状态/时间/操作人由后端代码填充
3. **职责分离**：接口层和数据层解耦

**业务规则补充**：管理员不能禁用自己（防止锁死自己账号），需在修改状态接口中校验当前登录人 id。
