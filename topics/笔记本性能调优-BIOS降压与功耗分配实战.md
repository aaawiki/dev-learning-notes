# 笔记本性能调优笔记：CPU 降压与功耗分配实战

> 日期：2026-08-02
> 标签：`笔记本` `BIOS` `CPU降压` `AC-Loadline` `功耗墙` `性能调优` `Intel`
> 类型：主题笔记（硬件/BiOS 调校）

---

## 一、核心功耗概念（Intel 平台）

### 1. PL1 与 PL2（功耗墙）

- **PL1（长时睿频功耗）**：CPU 在持续高负载（如游戏、渲染）下能维持的平均功耗上限。**撞墙即降频**。
- **PL2（短时睿频功耗）**：CPU 在短时爆发（如软件加载）允许达到的峰值功耗，通常维持几十秒（Tau 时间）。
- **注意**：BIOS 中的 `Platform PL1 Enable` 是**总开关**，必须设为 `Enabled`，手动调整才会生效。
- **PL4（瞬时峰值限制）**：微秒级的硬极限保险丝参数，**绝对不要动**，乱动极易黑屏断电。

> **笔记点**：PL1/PL2 仅指 **CPU 封装功耗**（Package Power），非整机总功耗。整机功耗由 EC（嵌入式控制器）和适配器功率决定。

---

## 二、核心操作：通过限制 CPU 为 GPU"让电"

笔记本供电和散热是**共享资源池**。压低 CPU 功耗，EC 检测到余量后，会动态将更多功耗和散热余量分配给独立显卡（GPU）。

### 2. 频率墙限制（硬压制）

- **P-core Turbo Ratio Limit**：直接锁死 P 核（性能核）的最高睿频倍频。
- **操作**：将 Core0~Core7 统一设为 `45`（即 4.5GHz）。默认通常为 `51`（5.1GHz）。
- **收益**：直接降低峰值电压需求，效果比单纯降 PL1 更"硬核"。
- **TRLR 含义**：`Turbo Ratio Limit Register`（基础寄存器），显示默认或生效的锚定值，**无需手动改动**。

### 3. 核心调度策略（取舍）

- **超线程（Hyper-Threading）**：建议**关闭**。可降低总功耗，对多数游戏帧数影响极小。
- **E 核（能效核）**：**不建议关闭**（尤其 Core Ultra 架构）。强制关闭易导致调度异常或性能骤降。

---

## 三、进阶操作：AC Loadline 降压（核心干货）

这是 BIOS 中最有效的降压手段，比软件降压（如 XTU）更底层、更稳定。

### 1. AC Loadline 与 DC Loadline 的本质区别

| 参数 | 作用 | 对功耗的影响 | 操作建议 |
| :--- | :--- | :--- | :--- |
| **AC Loadline** | 决定 CPU 向主板供电芯片**申请多少电压**。数值调低 = 直接降压。 | **真实有效**（省电、降温）。 | **核心调节项**。默认约 110-190，建议从 `110` 起步往下调。 |
| **DC Loadline** | 仅用于校准 CPU 内部功耗计算器的读数（电表校准）。 | **纯读数影响**（实际物理功耗不变）。 | **绝对不要动**。乱改会导致 EC 误判功耗，拒绝给 GPU 让电。 |

> **重要公式**：数值单位是 `1/100 mOhms`。例如 `110` = 1.10 mΩ。

### 2. CEP（Current Excursion Protection，电流过冲保护）

- **作用**：防止 CPU 因电流异常波动导致死机。
- **致命关联**：**调低 AC Loadline 降压时，必须关闭 CEP**，否则降压后的 CPU 性能会断崖式暴跌（频率极低），游戏帧数不升反降。
- **BIOS 路径**：通常在 AC Loadline 同级的 `VR Settings` 菜单中，将 `CEP Enable` 设为 `Disabled`。

---

## 四、必须避开的"雷区"选项

1. **PCIe Root Port 设置**：管理硬件插槽带宽（速度）。与供电功率无关，误关会导致显卡消失或硬盘不识别，**保持默认**。
2. **GT/Media VR Settings**：管理**核显**供电。乱调易导致核显花屏，**不要进入**。
3. **SA VR Settings**：管理系统代理（内存控制器）。乱调易导致内存蓝屏，**不要进入**。
4. **Overclocking Lock**：这是超频/降压权限的**大门总开关**。若要调 AC Loadline 或软件降压，必须设为 `Disabled`（解锁）。
5. **CFG Lock（MSR 0xE2）**：软件降压（ThrottleStop/XTU）的硬锁。若不关闭，软件设置的电压偏移会**被主板拦截，实际无效**。

## 五、实战故障排查（填错数值案例）

- **错误操作**：将 `AC Loadline` 误填为 `1100`（本应填 `110`）。
- **症状**：开机后**风扇不转、系统极度卡慢**（频率锁在 0.4~0.8GHz）。
- **原理**：CPU 错误申请极限高压，主板触发**强制降频保护（PROCHOT）**，强行锁死频率保命。风扇因温度低而停转。
- **解决方案**：长按电源键强制关机 → 进 BIOS 改回正确数值（110）→ F10 保存重启。
- **结论**：现代 CPU 有**电压硬上限（Current Voltage Limit）** 和**温度墙**，填错数字不会烧毁硬件，但会触发锁频保护，修改回来即可恢复。

---

## 六、关于虚拟化（Hyper-V）的特殊说明

- **游戏时建议关闭** `Hyper-V`、`虚拟机平台`、`Windows 虚拟机监控程序平台`。开启会持续占用 CPU 资源，并干扰核心调度，导致游戏帧率下降（实测影响 2%~5% 甚至更多）。
- **影响**：关闭后 VMware 性能恢复正常，但 **WSL 2 将无法启动**（依赖 Hyper-V 底层）。
- **解决方案**：如需兼顾开发（WSL）和游戏，可创建**双启动项**（一个开 Hyper-V，一个关 Hyper-V）灵活切换。

---

## 七、推荐组合拳策略（针对 Core Ultra 9 185H）

1. **BIOS 开关**：关闭 `Overclocking Lock`，关闭 `CEP`。
2. **锁功耗**：`PL1 = 45W`，`PL2 = 55W`（消除无用的抢电尖峰）。
3. **锁频率**：所有 P 核倍频统一设为 `45`（4.5GHz）。
4. **降压**：`AC Loadline` 设为 `110`（稳定起步），稳定后可尝试逐步降到 `80` 或 `60`。
5. **系统辅助**：关闭 Hyper-V（若无需 WSL），关闭 Windows"内存完整性"功能以降低额外开销。

## 核心要点速记

| 主题 | 一句话 |
|------|--------|
| PL1/PL2 | CPU 封装功耗墙；`Platform PL1 Enable` 是总开关；PL4 别动 |
| 让电逻辑 | 压低 CPU → EC 把余量分给 GPU；供电散热是共享池 |
| 频率墙 | P 核倍频锁 45（4.5G），比降 PL1 更硬核 |
| AC vs DC Loadline | AC 真实降压（调它）；DC 只改读数（别动） |
| CEP | 降压必须关 CEP，否则性能断崖式暴跌 |
| 雷区 | PCIe/GT/SA VR 保持默认；Overclocking Lock 设 Disabled；CFG Lock 挡软件降压 |
| 填错数值 | 误填 1100 触发 PROCHOT 锁频，改回即可，不会烧硬件 |
| Hyper-V | 游戏关、开发开 WSL 需开；冲突可建双启动项 |
| 验证 | 每次调完跑 Cinebench R23 压测 + HWMonitor 监控 |

---

> **笔记心得**：笔记本调优的核心是**平衡**——在"CPU 算力"、"GPU 功耗"、"散热能力"三者间做取舍。降压是唯一能"白嫖"降温且不减性能的操作，但务必先关 CEP。每次调整后务必运行 **Cinebench R23** 进行稳定性测试，并用 **HWMonitor** 监控实时功耗与温度。
